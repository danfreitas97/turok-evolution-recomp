# Changelog

What each release brings. The release workflow puts a version's section in
its GitHub release notes, and the launcher shows them in its NEWS card.
Write for players: one short line per change. Keep each version a `## <version>`
heading with a list under it, and no `---` lines.

## 1.0.0

- First release: Turok: Evolution, USA (NTSC), built from your own disc.
- Installer: checks your disc, builds the game in a portable folder and puts
  a shortcut on the desktop.
- Launcher: resolution up to 8x, widescreen, frame rate up to uncapped,
  fullscreen, frame interpolation, controls, English and Portuguese.
- Cheats tab: unlocks the game's own cheats in its Cheats menu.
- Back on the main menu closes the game.
- The launcher tells you when a new version is out.
- Linux and Mac builds are experimental.
