# Novidades

O que cada versão traz. O workflow de release coloca a seção da versão nas
notas do release no GitHub, e o launcher as mostra no card NOVIDADES.
Escreva para quem joga: uma linha curta por mudança. Mantenha cada versão como
um título `## <versão>` com uma lista embaixo, sem linhas `---`.

## 1.0.0

- Primeira versão: Turok: Evolution, USA (NTSC), compilado do seu próprio disco.
- Instalador: confere o disco, compila o jogo numa pasta portátil e cria um
  atalho na área de trabalho.
- Launcher: resolução até 8x, tela ampla, taxa de quadros até sem limite, tela
  cheia, interpolação de quadros, controles, inglês e português.
- Aba Cheats: libera os cheats do próprio jogo no menu Cheats dele.
- Back no menu principal fecha o jogo.
- O launcher avisa quando sai uma versão nova.
- Os builds de Linux e Mac são experimentais.
